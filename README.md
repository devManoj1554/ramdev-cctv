# Ramdev CCTV Management System

A modern management application for CCTV sales, installation services, and inventory tracking. Designed to streamline operations, customer record management, and service scheduling for CCTV businesses.

---

## 🚀 Key Features

- **Customer & Client Records:** Manage customer profiles, contact info, and installation history.
- **Inventory & Product Stock:** Track cameras, DVRs/NVRs, hard drives, cables, and accessory stock levels in real time.
- **Service & Maintenance Requests:** Log installation requests, routine checkups, and repair tickets.
- **Billing & Invoice Generation:** Create and manage service quotes, estimates, and customer invoices.
- **Dashboard & Analytics:** Overview of active installations, pending service jobs, and low stock alerts.

---

## 🛠 Tech Stack

- **Backend:** Java (Spring Boot)
- **Frontend:** React
- **Database:** PostgreSQL
- **Authentication:** JWT
